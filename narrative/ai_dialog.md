`SyntaxError: invalid syntax` 是 **Python 解释器**才会报的错，说明那条命令被敲进了 Python，而不是命令行。三种常见情形：

| 报错里第一行长什么样 | 你实际在哪 | 怎么退出／改 |
|---|---|---|
| `File "<stdin>", line 1` | Python 交互界面，提示符是 `>>>` | 输入 `exit()` 回车，回到命令行；`conda`、`cd`、`python` 这些要在命令行敲 |
| `File "...\某文件.py", line N`，第 N 行是 `conda ...` / `cd ...` | 把命令行命令存进了 `.py` | `.py` 里只能放 Python 代码 |
| 报错出现在 JupyterLab 或 VS Code 的单元格里 | 单元格只认 Python | 打开「Terminal」面板，命令敲在那里 |

判断自己在哪：提示符是 `>>>` 就是 Python；是 `(shipping) C:\...>` 或 `(base) C:\...>` 才……
